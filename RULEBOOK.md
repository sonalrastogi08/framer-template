# Template Rulebook

Rules for building this Framer template. Each rule is added as the owner states it.

## Rules

1. **Fonts: use only free fonts from Framer's built-in font picker.** Pick fonts only from the Fonts panel's free sources (filters such as Google, Fontshare, Open source, Variable). Do not use paid, custom-uploaded, or externally licensed fonts, so the template works for any buyer without extra licenses.
2. **Animation: use Framer Motion and GSAP.** Build animations with Framer Motion (Framer's native animation) and GSAP.
